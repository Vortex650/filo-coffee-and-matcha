# UI/UX Design Direction

## Brand
- Filo Red #9C2626 (primary, buttons, accents)
- Filo Cream #F9F1E6 (backgrounds, text on red)
- Ink #2A1A17 (body text)
- Matcha Green (TBD, placeholder #7A8F6B)

## Typography
- Headings: Fraunces (Google Fonts)
- Body: Inter

## Visual
Editorial, generous whitespace, thin borders, clean layouts, subtle transitions, minimal shadows, square/slightly rounded photography. Avoid generic templates, heavy gradients, heavy shadows, clutter.

## Components
Tailwind 4 + Flowbite React. Reusable: Button, Card, Input, Modal, Badge, StarIcon (4-point).

## Accessibility
WCAG 2.2 AA: keyboard nav, visible focus, semantic HTML, heading hierarchy, labels, error messages, contrast, reduced motion.

## Responsive
Mobile-first customers, tablet-first staff.
